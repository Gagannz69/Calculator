# Simple Calculator

A clean and simple web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Clear (`C`) and single-digit delete (`DEL`) functionality
- Responsive grid layout with a dark theme
- Keyboard support (numbers, operators, Enter to calculate, Escape to clear, Backspace to delete)

## Tech Stack

- **HTML5** - Structure and layout
- **CSS3** - Styling and grid design
- **JavaScript** - Calculation logic and event handling

## Deploy on Vercel

The easiest way to deploy this project is via [Vercel](https://vercel.com):

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import your repository.
3. Keep default settings (Framework Preset: **Other**) and click **Deploy**.

## How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open `index.html` directly in your browser, or run a local server:
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your web browser.
